## 🚀 HOW TO RUN EVERYTHING

### Complete Startup Sequence:

```bash
# Terminal 1: Database Setup
python setup_database.py

# Terminal 2: API Server (with WebSocket)
python api/main.py

# Terminal 3: Start Real-Time Services
python -c "from backend.realtime.scheduler import initialize_scheduler; initialize_scheduler()"

# Terminal 4: Run Pipeline
python main_pipeline_upgraded.py

# Terminal 5: Dashboard UI
streamlit run dashboard.py
```

### URLs:
- **API**: http://localhost:8000
- **API Docs**: http://localhost:8000/docs
- **WebSocket**: ws://localhost:8000/ws
- **Dashboard**: http://localhost:8501
